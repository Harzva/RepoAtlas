# RepoAtlas Agent Tools

RepoAtlas can be used by agents in two complementary ways:

- **MCP server**: fast structured lookups from a RepoAtlas inventory JSON file.
- **Codex skill**: repeatable workflow for generating, refreshing, and installing the MCP-backed repo map.

Use MCP when an agent needs a small answer such as "where is `owner/repo` locally?". Use the skill when an agent needs the operating procedure, install instructions, or a map refresh workflow.

## MCP Server

Register the stdio MCP server in Codex:

```toml
[mcp_servers.repoatlas]
command = "python"
args = [
  "C:\\path\\to\\RepoAtlas\\agent-tools\\mcp\\repoatlas_mcp_server.py",
  "--inventory",
  "C:\\path\\to\\repo-atlas.json",
]
startup_timeout_sec = 30
```

`--inventory` can point to:

- `repo-atlas.json` exported from the RepoAtlas desktop app.
- The app's `REPO_ATLAS_DATA` inventory JSON.
- A compact `repoatlas-local-address-map.json` generated by the Codex skill.

Available tools:

- `repoatlas_summary`: inventory counts and source metadata.
- `repoatlas_find_repo`: find a repository by `owner/repo`, GitHub URL, or partial text.
- `repoatlas_missing_local_copies`: list remotes without local checkouts.
- `repoatlas_needs_attention`: list dirty, ahead, behind, diverged, or no-upstream local repos.

## Codex Skill

Install the skill by copying this folder:

```powershell
Copy-Item -Recurse .\agent-tools\repoatlas-repo-map "$env:USERPROFILE\.codex\skills\repoatlas-repo-map"
```

Then ask Codex:

```text
Use $repoatlas-repo-map to query whether Harzva/RepoAtlas exists locally.
```

The skill explains when to refresh the map, when to call the MCP tool, and how to report results without loading the full inventory into context.

## Recommended Agent Workflow

1. Use RepoAtlas desktop to scan GitHub accounts and local roots.
2. Export `repo-atlas.json`, or set `REPO_ATLAS_DATA` to the live inventory path.
3. Register `repoatlas_mcp_server.py` in Codex.
4. Ask the agent focused questions:

```text
Find local paths for Just-Agent/readme-ddl.
List the first 20 repos that are missing local copies.
Show repos that are diverged or dirty.
```

The agent receives small structured results instead of spending tokens reading a large Markdown or JSON report.

## Benchmark

Run the included benchmark to compare the bundled traditional `gh-repo-cartographer` scan with focused RepoAtlas MCP lookup:

```powershell
python .\agent-tools\benchmarks\repoatlas_benchmark.py `
  --scan-root "C:\path\to\your\workspace" `
  --no-fetch `
  --query "Harzva/RepoAtlas"
```

The baseline cartographer skill lives in `agent-tools/gh-repo-cartographer/`, so public users do not need a private local Codex skill path to reproduce the experiment.

The benchmark reports:

- remote scan time
- local Git discovery time
- local repository inspection time
- full traditional report size and estimated tokens
- focused MCP query latency and estimated response tokens
- speed and output-size ratios

Outputs are written under `agent-tools/benchmarks/output/`.
