Harzva Repo Atlas

A Windows desktop atlas for mapping Harzva GitHub repositories to local Git checkouts, spotting drift, and opening the right project folder without hunting through directories.

Download for Windows Quick Start

One place for remote repos and local reality.

Repo Atlas packages the cartography workflow into a desktop app: remote repository inventory, local Git discovery, sync state comparison, private/public/fork filters, report exports, and safe folder opening.

GitHub inventory

Lists owned repositories through GitHub CLI, including visibility, language, default branch, and last push.

Local matching

Scans Git folders and maps remotes back to GitHub repository keys.

Drift signals

Highlights synced, behind, ahead, diverged, dirty, no-upstream, and missing-local states.

Desktop actions

Open matched local folders, copy clone URLs, export CSV/Markdown/JSON, and rescan from the app.

Install

Portable exe, no installer ceremony.

Download the release asset, run it, and sign in with GitHub CLI if you want live rescans. The bundled seed inventory keeps the dashboard useful immediately.

gh auth login git --version Harzva-Repo-Atlas-0.1.0-x64.exe
