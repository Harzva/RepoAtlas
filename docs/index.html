RepoAtlas

A Windows desktop atlas for mapping any GitHub account's repositories to local Git checkouts, spotting drift, and opening the right project folder without hunting through directories.

Download for Windows Quick Start

One place for remote repos and local reality.

RepoAtlas packages repository cartography into a desktop app: GitHub inventory, local Git discovery, sync comparison, private/public/fork filters, report exports, and safe folder opening.

GitHub inventory

Lists owned repositories through GitHub CLI, including visibility, language, default branch, and last push.

Local matching

Scans Git folders and maps remotes back to normalized GitHub repository keys.

Drift signals

Highlights synced, behind, ahead, diverged, dirty, no-upstream, and missing-local states.

Desktop actions

Open matched folders, copy clone URLs, export CSV/Markdown/JSON, and rescan from the app.

Install

Portable exe, no installer ceremony.

Download the release asset, run it, and sign in with GitHub CLI for live rescans. The first launch starts with an empty seed inventory and fills itself from your account.

gh auth login git --version RepoAtlas-v0.2.0-x64.exe
