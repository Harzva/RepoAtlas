First run guide

Connect GitHub and local context

1. Choose a login path

RepoAtlas delegates GitHub authentication to GitHub CLI. The app does not ask for, store, or import your GitHub password or token.

Recommended in app Click Login in the sidebar
Terminal equivalent gh auth login --web
Check status gh auth status

2. Understand account modes

  • Leave GitHub accounts empty to scan the active `gh` login.
  • Enter one account or alias per line for multi-account scans.
  • Private repositories require a login or router alias that can access that account.
  • Token/headless login belongs in GitHub CLI: `gh auth login --with-token`, not inside RepoAtlas.

3. Add local scan roots

Scan roots are the local folders where your Git repositories live. RepoAtlas matches local remotes to GitHub repository keys and then enables folder actions.

C:\Users\you\Projects D:\work\repos

4. Press Refresh

Refresh lists remote repositories, scans local Git folders, classifies categories, and shows drift. If anything fails, the error stays visible above the metrics.

New user checklist: Git installed, GitHub CLI installed, `gh auth login` completed, optional account aliases, optional scan roots.
